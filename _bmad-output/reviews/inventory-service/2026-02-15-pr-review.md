## Critical Issues (Must Fix)

### 1. NO TEST COVERAGE
**File:** `services/inventory-service/src/test/`
**Issue:** Only `.gitkeep` file exists - no tests implemented
**Required:** Minimum 80% coverage per Definition of Done
**Impact:** Cannot verify service functionality, blocks production readiness

### 2. Scheduled Job Syntax Error
**File:** `ReservationService.java:150`
```java
@Scheduled(fixedRateString = "${inventory.reservation.cleanup-interval-minutes:5}m", ...)
```
**Issue:** `5m` suffix is invalid - Spring expects milliseconds
**Fix:** Use `fixedRate = 300000` or `cron = "0 */5 * * * *"`

### 3. Type Safety Issue in checkAvailability
**File:** `InventoryController.java:121`
```java
public ResponseEntity<?> checkAvailability(@Valid @RequestBody Object request)
```
**Issue:** Using `Object` type with `instanceof` checks fails with JSON deserialization
**Fix:** Create proper request DTO or separate endpoints

### 4. Missing Event Schema File
**Required:** `shared/event-schemas/inventory-service-events.json`
**Impact:** Other services cannot validate event contracts
