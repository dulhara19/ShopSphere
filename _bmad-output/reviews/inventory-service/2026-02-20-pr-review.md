## New Endpoints Added

### Bulk Update (Story 1.1.4)
```
POST /inventory/bulk-update
```
- Accepts list of product updates
- Returns success/failure per item
- Returns HTTP 207 Multi-Status on partial failures

### Stock History (Phase 2)
```
GET  /inventory/{productId}/history
POST /inventory/{productId}/adjustment
```

### Analytics (Phase 2)
```
GET /inventory/analytics/turnover
GET /inventory/analytics/days-remaining
GET /inventory/analytics/dead-stock
GET /inventory/analytics/valuation
GET /inventory/{productId}/restock-recommendation
GET /inventory/forecasts
```
