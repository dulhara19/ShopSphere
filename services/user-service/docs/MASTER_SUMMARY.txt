ENDPOINT SPECIFICATIONS
═══════════════════════════════════════════════════════════════════════════

POST /api/auth/register

REQUEST (JSON):
{
  "firstName": "string (2-50 chars, required)",
  "lastName": "string (2-50 chars, required)",
  "email": "string (valid format, required, unique)",
  "password": "string (8-100 chars, required)",
  "roles": ["CUSTOMER"] (optional, defaults to CUSTOMER)
}

RESPONSE (201 Created):
{
  "userId": "uuid",
  "email": "string",
  "firstName": "string",
  "lastName": "string",
  "message": "User registered successfully"
}

ERROR RESPONSES:
- 409 Conflict: Email already exists
- 400 Bad Request: Validation failed (with field errors)
- 500 Internal Server Error: Unexpected error

ARCHITECTURE & DESIGN
═══════════════════════════════════════════════════════════════════════════

Layered Architecture:

┌─────────────────────────────────────────┐
│     AuthController (REST Endpoint)      │
│  POST /api/auth/register                │
└────────────────┬────────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────────┐
│      AuthService (Business Logic)       │
│  - Validate email uniqueness            │
│  - Encode password with BCrypt          │
│  - Create User entity                   │
│  - Log operations                       │
└────────────────┬────────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────────┐
│  UserRepository (Data Access Layer)     │
│  - JpaRepository<User, UUID>            │
│  - findByEmail(String email)            │
│  - existsByEmail(String email)          │
└────────────────┬────────────────────────┘
                 │
                 ▼
┌─────────────────────────────────────────┐
│   PostgreSQL Database (users table)     │
│  - User data persistence                │
│  - UNIQUE constraint on email           │
│  - UUID primary key                     │
└─────────────────────────────────────────┘

Cross-Cutting Concerns:

├─ GlobalExceptionHandler
│  └─ Unified error responses
├─ Validation
│  └─ @Valid + @NotBlank, @Email, @Size
├─ Logging
│  └─ SLF4J with @Slf4j
├─ Security
│  └─ BCryptPasswordEncoder
└─ Transactions
   └─ @Transactional
